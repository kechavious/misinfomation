# Changelog

## 1.0.0

- Unified the notebook and modules around synchronous, repeated-attempt SI diffusion.
- Added seeded CLI experiments, independent graph replicates, per-trial records,
  metadata and pointwise confidence intervals.

- Added a Watts–Strogatz rewiring comparison with explicit causal limitations.
- Added installable packaging, behavioral tests and GitHub Actions checks.
- Rebuilt the README, figures, notebook and reproducibility documentation.
- Preserved original coursework artifacts and results in `docs/archive/`.

# Original coursework archive

These materials preserve the original project, including its paper, presentation,
notebook and numerical results. They are historical artifacts, not outputs of the
current reproducible workflow. The license and authorship notices are retained.

The original notebook and standalone modules implemented different diffusion
rules, and the paper's stated experiment sizes and trial counts did not match the
notebook defaults. Claims about external validation, scaling invariance and a
causal clustering effect are not established by the experiment records retained
here. The original logistic midpoint was also sometimes described interchangeably
with an 80% adoption threshold. The current project separates those quantities.

Use the main README, `docs/methodology.md` and `results/metadata.json` for the
current model, evidence and limitations. Archived PDFs and slides have not been
rewritten and should not be presented as the current study.

# Project history and provenance

This repository began as a Social Networks coursework project at New York
University. The original writeup attributes the work to Gordon Zou. The existing
MIT license and its copyright notice remain unchanged.

The current implementation and report replace the original presentation of the
study. Earlier artifacts used inconsistent simulation rules and experiment
counts, and sometimes conflated logistic midpoints with 80% adoption thresholds.
Claims about external validation, finite-size scaling and isolated clustering
effects were not supported by the retained numerical records.

Old PDFs, slides, duplicate results and the notebook checkpoint have been removed
from the current project tree to keep the published version unambiguous. They
remain available in Git history:

- [Original coursework snapshot](https://github.com/kechavious/misinfomation/tree/dc42d2a9eadce48c088a783082b3551f37486c7a)
- [Original paper source](https://github.com/kechavious/misinfomation/blob/dc42d2a9eadce48c088a783082b3551f37486c7a/Writeup/paper.md)
- [First reproducible portfolio revision](https://github.com/kechavious/misinfomation/tree/42c094728efae873a8b279d80304edaba80e8b74)

Use `docs/paper.md`, `docs/paper.pdf` and `results/metadata.json` for the current
report and evidence. Git history preserves prior versions; they should not be
presented as outputs of the current model.
